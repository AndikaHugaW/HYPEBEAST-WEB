# Service Page Images

Folder ini digunakan untuk menyimpan gambar-gambar yang digunakan pada halaman service.

## Struktur File

Gambar-gambar yang disimpan di sini dapat diakses melalui path:
- `/images/service/[nama-file]`

## Contoh Penggunaan

```tsx
<Image
  src="/images/service/nama-gambar.png"
  alt="Description"
  fill
  className="object-cover"
/>
```
